`cspa-tui-demo` is a standalone `#![forbid(unsafe_code)]` interactive terminal studio built with `ratatui`, `crossterm`, `rustfft`, and `cpal` directly on top of the unified `capture-system-or-process-audio` Rust facade (`0` OS-specific `#[cfg]` branches in `backend.rs`).

It lets you browse live applications, processes, output endpoints, and microphones, preview side-effect-free `CaptureRequest::inspect()` execution plans, inspect or request OS privacy permissions, hot-swap mixes **while recording**, play back zero-disk RAM takes, and export WAV files — without writing a line of code.

---

## 1. Quick Launch & CLI Modes

### Prebuilt Binary *(Zero Rust Toolchain Needed)*
Download `cspa-tui-demo-<version>-<target>.zip` (Windows `x64`/`ARM64`) or `.tar.gz` (Linux `x86_64`/`aarch64`, macOS `arm64`) from [GitHub Releases](https://github.com/s0d3s/capture-system-or-process-audio/releases/latest) and run it in any truecolor terminal (**`100x36` or larger** recommended):

```bash
# Linux & macOS:
./cspa-tui-demo

# Windows Terminal / PowerShell:
.\cspa-tui-demo.exe
```

### Build & Smoke-Test From Source

```bash
cargo run --release --manifest-path tools/cspa-tui-demo/Cargo.toml

# Non-interactive headless self-test (used in CI release smoke checks):
cargo run --release --manifest-path tools/cspa-tui-demo/Cargo.toml -- --smoke-test
```

## 3. Acoustic Feedback Loop Guard

<Aside type="tip" title="Why live monitoring never howls through your speakers">
When you stage a `[MIC]` source alongside `[SYS]` speakers, routing live captured audio back to speakers would immediately trigger an acoustic feedback loop. `cspa-tui-demo`'s live monitor (`[Mon: ON (M)]`) is **100% visual** (driving the FFT, Waterfall, Oscilloscope, dBFS meters, and Voice Strip without speaker output) and automatically pauses live monitoring whenever `cpal` plays back a recorded `MemoryTake` (`P`).
</Aside>
