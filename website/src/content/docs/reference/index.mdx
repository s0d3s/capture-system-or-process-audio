## Cross-SDK Concept & Symbol Concordance

The Python examples use `import capture_system_or_process_audio as cspa`.

| Concept | Python (`capture_system_or_process_audio`) | Rust (`capture_system_or_process_audio`) | C++17 (`cspa::*`) | C11 (`cspa_experimental.h`) |
| --- | --- | --- | --- | --- |
| **Default Speakers** | `cspa.default_output(default_device_mode="follow")` | `CaptureTarget::default_output(DefaultDeviceMode::Follow)` | `cspa::Target::default_output(...)` | `cspa_target_default_output(...)` |
| **Default Microphone** | `cspa.microphone(default_device_mode="follow")` | `CaptureTarget::microphone(DefaultDeviceMode::Follow)` | `cspa::Target::microphone(...)` | `cspa_target_microphone(...)` |
| **List & Filter Targets** | `cspa.discover()` / `cspa.discover_query(query)` | `discover_query(&query)` $\rightarrow$ `TargetCatalog` | `cspa::Discovery::query(query)` | `cspa_discover_query(&q, buf, cap, &n)` |
| **Find Single App** | `cspa.find_app("Zoom", scope="tree")` | `Discovery::new().find_app("Zoom", ...)` | `cspa::Discovery::query(...)` | `cspa_discovery_find_app(...)` |
| **Process by PID** | `cspa.process(pid, scope="tree")` | `CaptureTarget::process(pid, ...)` | `cspa::Target::process(pid, ...)` | `cspa_target_process(...)` |
| **Plan Inspection** | `cspa.request(targets).inspect()` | `request(targets).inspect()` | `req.inspect()` / `inspect_or_throw()` | `cspa_request_inspect(&req, &rep)` |
| **Managed Capture** | `cspa.capture(targets, ...)` $\rightarrow$ `ManagedStream` | `CaptureManager::open(req)` | `cspa::ManagedStream::open(req)` | `cspa_manager_open(&req, &mgr)` |
| **Zero-Alloc Pull** | `stream.read_into(buf, frames)` | `manager.read_into(&mut buf, frames, timeout)` | `stream.read_into(ptr, len, frames, ms)` | `cspa_manager_read_into(...)` |
| **Live Hot-Swap** | `stream.update_targets(new_targets)` | `manager.update_targets(new_targets)` | `stream.update_targets(new_targets)` | `cspa_manager_update_targets(...)` |
| **Format Converter** | `cspa.OutputConverter(rate, channels, ...)` | `OutputConverterConfig` | `cspa::OutputConverter` | `cspa_output_converter_record` |
| **Mixer Config** | `cspa.MixerConfig(...)` / `silence_on_idle=True` | `MixerConfig` | `cspa::MixerConfig` | `cspa_mixer_config_record` |
| **Permissions Check** | `cspa.check_permissions(targets)` | `check_permissions(targets)` | `cspa::check_permissions(targets)` | `cspa_permissions_check(...)` |
