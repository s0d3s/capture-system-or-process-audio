## 1. `CaptureManager` (`capture`) vs `AudioStream` (`open_stream`)

| Question | Use `CaptureManager` / `ManagedStream` *(Recommended Default)* | Use `AudioStream` *(Advanced Single-Session)* |
| --- | --- | --- |
| **Single speaker, mic, or app?** | ✅ Uses zero-extra-copy `PassThrough` automatically when no mixing/conversion is needed. | ✅ Opens one raw OS session directly. |
| **Follow OS default speaker/mic switches?** | ✅ `DefaultDeviceMode::Follow` seamlessly closes old and opens new endpoints. | ❌ Never monitors device switches (`Follow` requires `CaptureManager`). |
| **Mix multiple sources (`[mic, app]`)?** | ✅ Orchestrates `SharedNativeGraphMix` or `CspaMixer` automatically. | ❌ Single target only. |
| **Resample / convert format (`16 kHz` `i16`/`f32`)?** | ✅ Built-in `OutputConverter` + `silence_on_idle`. | ❌ Native OS device format only. |
| **Wait for app relaunch (`OnRootExit::Wait`) or hot-swap targets?** | ✅ Supported (`update_targets`). | ❌ Ends on session exit. |

---

## 2. `Follow` vs `Pin` Default Endpoints

- **`Follow` *(Default)*:** When a user plugs in USB/Bluetooth headphones or changes their default microphone in OS settings, `CaptureManager` detects the change via native event listeners (`IMMNotificationClient`, PipeWire/Pulse metadata, `AudioObjectAddPropertyListener`) and transitions the stream automatically, emitting a `Boundary` marker so downstream consumers know when hardware changed.
- **`Pin`:** Resolves the current default output or microphone ID once at open time and stays bound to that specific endpoint even if the OS default changes later.

## 4. When Should You Enable `silence_on_idle`?

On Windows WASAPI loopback and per-process taps, the OS emits **zero packets** while all audio playback is paused.
- Leave `silence_on_idle=False` *(default)* when recording only active audio bursts or event-driven streams.
- Set **`silence_on_idle=True`** whenever feeding continuous wall-clock consumers (WebRTC, Discord bots, VADs, or `PyAudio`-style blocking loops) so idle periods emit metadata-flagged silent frames (`synthesized_silence = true`) instead of timing out.
